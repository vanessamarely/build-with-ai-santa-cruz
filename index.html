El chatbot no siempre es la respuesta

Hoy cada empresa monta un chatbot sobre su propio modelo: soporte, FAQ, dudas de producto. Pero el usuario sigue cargando con todo el trabajo.

Sale del flujo, abre el widget, redacta la pregunta, espera la respuesta y vuelve a ubicarse en la pantalla. Eso también es carga cognitiva.

>  UX: USER_DOES_THE_WORK — MODEL_LIVES_FAR_AWAY

[!] CHATBOT FATIGUE
  • Context switching — abrir el widget, perder de vista el componente.
  • El usuario redacta la pregunta — la app ya sabe qué está mirando.
  • Round-trip de red + tokens — latencia y costo por cada duda.

CSS Anchor Positioning

Acopla un elemento flotante a otro de forma declarativa. Tres capacidades nucleares (MDN):

01 · ASOCIAR
anchor-name en el ancla · position-anchor en el flotante.
02 · POSICIONAR
position-area con keywords (top, bottom span-inline…) o la función anchor().
03 · SOBREVIVIR
position-try-fallbacks para reubicar si se sale del viewport.

Párrafo activo — ancla del popover.

// CSS only · zero JS
// help panel
Anclado a #anchor-src.
position-area: right span-block;
⚠ Anchor positioning aún no está disponible en este navegador.
anchor.css · mdn.io/anchor-positioning
/* 1. Declarar el ancla */
#active {
  anchor-name: --active;
}

/* 2. Asociar y posicionar */
#help-panel {
  position: fixed;
  position-anchor: --active;
  position-area: right span-block;
  margin-inline-start: 16px;

  /* 3. Reubicar si overflowea */
  position-try-fallbacks:
    flip-block, flip-inline;
}

/* O con la función anchor() */
.tooltip {
  top: anchor(--active bottom);
  width: anchor-size(--active width);
}

View Transitions API

El navegador toma snapshots automáticos del DOM antes y después de la mutación, y los interpola. Funciona en SPA y MPA (MDN).

01 · SPA — SINGLE PAGE APP
document.startViewTransition(cb) envuelve una mutación del DOM. Es lo que usa el panel.
02 · MPA — MULTI-PAGE APP
At-rule @view-transition activa transiciones entre páginas distintas. No aplica a nuestro panel.
03 · CUSTOM
view-transition-name aísla elementos. Pseudo-elementos ::view-transition-old / new orquestan el detalle.
// HELP-PANEL · EMPTY
// startViewTransition
snapshot & interpolate
view-transitions · mdn.io/view-transition-api
// SPA — panel en la misma página
function openHelpPanel(summary) {
  // Fallback si no hay soporte
  if (!document.startViewTransition) {
    render(summary); return;
  }
  document.startViewTransition(
    () => render(summary)
  );
}

/* Aislar el panel del resto */
#help-panel {
  view-transition-name: help;
}
::view-transition-old(help),
::view-transition-new(help) {
  animation-duration: 280ms;
}

/* A11y: prefers-reduced-motion → none */

Summarizer API

Resume cualquier texto del DOM usando el modelo interno del navegador. Promise-based (MDN).

01 · STATIC METHODS
Summarizer.availability(opts) y Summarizer.create(opts). Estados: available, downloading, unavailable.
02 · OPCIONES
type: tldr · key-points · teaser · headline. length, format, sharedContext, expectedInputLanguages, outputLanguage.
03 · INSTANCE METHODS
summarize(text) → string · summarizeStreaming(text) → ReadableStream · measureInputUsage() · destroy().
! HTTPS + transient user activation (click reciente).
! monitor() reporta downloadprogress mientras el modelo se descarga.
! Cancela con ctrl.abort() al cerrar el panel; libera con destroy().
summarizer · mdn.io/summarizer-api
// 1. Disponibilidad del modelo
if (!('Summarizer' in self)) return;
const av = await Summarizer.availability();
if (av === 'unavailable') return;

// 2. Crear (monitor + AbortController)
const ctrl = new AbortController();
const sum = await Summarizer.create({
  type: 'key-points', length: 'short',
  format: 'markdown',
  sharedContext: 'Asistente UX.',
  expectedInputLanguages: ['es'],
  signal: ctrl.signal,
  monitor: m => m.addEventListener(
    'downloadprogress', e => setProgress(e.loaded)
  ),
});

// 3. Streaming directo al panel
for await (const c of sum.summarizeStreaming(text)) {
  panel.textContent += c;
}

// 4. Cancelar + liberar al cerrar
panel.addEventListener('toggle', e =>
  e.newState === 'closed' && (ctrl.abort(), sum.destroy())
);

Prompt API

Razonamiento local sobre el DOM con sesiones conversacionales. Multimodal: texto, imagen y audio (Chrome docs).

01 · STATIC METHODS
LanguageModel.availability(opts) y LanguageModel.create(opts) — comparten las mismas opciones.
02 · SESSION SETUP
initialPrompts: system/user/assistant. expectedInputs: text/image/audio. monitor, signal, responseConstraint (JSON Schema).
03 · SESSION INSTANCE
prompt(text) · promptStreaming(text) → ReadableStream · append() · clone() · measureInputUsage() · destroy().
! Inputs: texto, imagen, audio. Output: solo texto.
! Monitorea: session.contextUsage / session.contextWindow. Escucha 'contextoverflow'.
! En iframes cross-origin: allow="language-model". No funciona en Web Workers.
prompt · developer.chrome.com/docs/ai/prompt-api
// 1. Disponibilidad (mismas opts que create)
const av = await LanguageModel.availability();
if (av === 'unavailable') return;

// 2. Sesión con system prompt + monitor
const ctrl = new AbortController();
const session = await LanguageModel.create({
  expectedInputs: [{ type: 'text', languages: ['es'] }],
  initialPrompts: [
    { role: 'system',
      content: 'Asistente UX. Responde en 2 frases.' },
    { role: 'user',
      content: `Contexto: ${active.innerText}` },
  ],
  signal: ctrl.signal,
  monitor: m => m.addEventListener(
    'downloadprogress', e => setProgress(e.loaded)
  ),
});

// 3. Streaming directo al panel
for await (const c of session.promptStreaming(q)) {
  help.textContent += c;
}

// 4. Cleanup al cerrar el panel
panel.addEventListener('toggle', e =>
  e.newState === 'closed' && (ctrl.abort(), session.destroy())
);

Hay más: el ecosistema built-in AI

En esta charla solo usamos Summarizer y Prompt para el panel. Pero el navegador trae más APIs de IA que podés combinar:

// 01 — DETECTION

Language Detector

Detecta el idioma de cualquier texto del DOM. Ideal antes de traducir.

LanguageDetector.detect(text)
// 02 — TRANSLATION

Translator

Traduce offline entre idiomas con language packs locales.

Translator.create({source, target})
// 03 — GENERATION

Writer

Genera texto nuevo: emails, reseñas, borradores. Tono y longitud configurables.

writer.write(prompt, { context })
// 04 — REVISION

Rewriter

Refactoriza tono y longitud de texto existente: más formal, más casual, más corto.

rewriter.rewrite(text, { tone })
// 05 — PROOFREAD

Proofreader

Corrige gramática, ortografía y puntuación. Devuelve correcciones con etiquetas.

proofreader.proofread(text)

Checklist: privacidad & producción

01
Feature Detection estricto
Valida window.ai antes de renderizar la UI del asistente. Sin modelo, sin botón.
02
Model Weights Management
Notifica visualmente la carga de pesos del modelo local (~1.5 GB). Estado, progreso, retry.
03
Sanitización obligatoria
Filtra el output antes de inyectarlo en el DOM. Mitiga Prompt Injection en cada inserción.
04
Zero Local Persistence
No almacenes prompts sensibles en localStorage. Sesión efímera, memoria limpia al cierre.
